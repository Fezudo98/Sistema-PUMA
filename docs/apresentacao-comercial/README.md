# Apresentação Comercial — Sistema PUMA

Material de vendas (`Sistema_PUMA_Apresentacao_Comercial.pptx`) para apresentar o Sistema PUMA como case de referência na oferta de plataformas semelhantes (simulados ao vivo, IA generativa e gamificação) a outras instituições de ensino.

## Conteúdo (13 slides)

1. Capa
2. O desafio das instituições de ensino
3. Visão geral da solução (6 diferenciais)
4. Case comprovado: 32º Pelotão PUMA (CFSD PMCE)
5. Telas de acesso (instrutor / aluno)
6. IA generativa de simulados a partir de PDF
7. Painel do instrutor (dashboards e relatórios)
8. Painel gamificado do aluno
9. Gestão administrativa (inventário, auditoria)
10. Stack tecnológica
11. Personalização / white-label para outras instituições
12. Modelo comercial (planos Essencial / Profissional / Institucional)
13. Contato / chamada para ação

## Como foi gerado

Os prints de tela foram capturados de uma instância local do próprio Sistema PUMA (dados fictícios de demonstração), e o deck foi montado com `pptxgenjs`. Os scripts de geração não fazem parte do produto e não foram versionados — apenas o `.pptx` final.

## Antes de usar comercialmente

Os valores dos planos (slide 12) estão como exemplo e devem ser ajustados. Substitua também o e-mail de contato do slide final pelo canal comercial oficial da empresa, se for diferente de `fernandoplaysson11@gmail.com`.
